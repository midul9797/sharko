Detailed Description of the "Sharko" Predictive Model Stack
​The "Sharko" project employs a sophisticated, multi-tiered machine learning model stack designed to sequentially predict future oceanographic conditions and then, based on these predictions, infer the probability of shark presence. This cascade architecture mirrors the natural dependencies within marine ecosystems and allows for robust, future-looking predictions.
​1. Overall Architecture: A Predictive Cascade
​Our system operates in two primary tiers:
​Tier 1: Environmental Forecasting Models (Regression Models): Three independent regression models are trained to predict the key oceanographic features (SST, SSHA, Chlorophyll-a). These models learn the spatio-temporal dynamics of the ocean.
​Tier 2: Shark Presence Prediction Model (Classification Model): The output predictions from Tier 1 (future SST, SSHA, Chlorophyll-a) are then fed, along with latitude, longitude, and seasonal components, into a final classification model. This model learns the complex relationships between these environmental conditions and the likelihood of shark presence.
​This cascade approach is critical for our goal of future prediction, as it allows the entire system to forecast shark hotspots based on anticipated environmental states, not just historical correlations.
​2. Tier 1: Environmental Forecasting Models
​For each of the three environmental variables (SST, SSHA, Chlorophyll-a), we developed and fine-tuned a dedicated model.
​Model Type:
​Light Gradient Boosting Machine (LightGBM) Regressors: We selected LightGBM due to its efficiency, speed, and high performance on tabular data. Its gradient boosting framework is robust to various data distributions and capable of capturing complex non-linear relationships.  
​Feature Set: Each environmental model was trained using geographical coordinates (latitude, longitude) and temporal features (day_sin, day_cos). Crucially, the SSHA and Chlorophyll-a models also incorporated the predicted SST from the previous step in the cascade, reflecting the real-world influence of temperature on other oceanographic processes.
​SST Model Features: latitude, longitude, day_sin, day_cos
​SSHA Model Features: latitude, longitude, day_sin, day_cos, predicted_sst
​Chlorophyll-a Model Features: latitude, longitude, day_sin, day_cos, predicted_sst, predicted_ssha
​Training Data: The models were trained on the entire historical environmental dataset (2020-2025), with the corresponding latitude, longitude, day_sin, and day_cos values.
​Hyperparameter Tuning (Optuna):
​Methodology: We employed Optuna, an open-source hyperparameter optimization framework, to systematically search for the best combination of parameters for each LightGBM regressor. Optuna uses an efficient pruning algorithm (e.g., TPE Sampler) to quickly converge on optimal solutions.  
​Objective Function: The objective for Optuna was to minimize the Mean Squared Error (MSE) of the model on a validation set.
​Key Parameters Optimized:
​n_estimators: The number of boosting rounds (trees).
​learning_rate: Step size shrinkage to prevent overfitting.  
​num_leaves: Maximum number of leaves in one tree.
​max_depth: Maximum tree depth.
​min_child_samples: Minimum number of data needed in a child (leaf).
​subsample: Fraction of samples to be randomly sampled for each tree.
​colsample_bytree: Fraction of features to be randomly sampled for each tree.
​reg_alpha, reg_lambda: L1 and L2 regularization terms.  
​Performance: The optimized environmental models demonstrated exceptionally high accuracy, with the SST model, for instance, achieving an R-squared value exceeding 0.97. This robust performance ensures that the downstream shark prediction model receives highly reliable environmental inputs.
​3. Tier 2: Shark Presence Prediction Model
​The final stage of the cascade utilizes the predictions from the environmental models to forecast shark presence.
​Model Type:
​Light Gradient Boosting Machine (LightGBM) Classifier: Again, LightGBM was chosen for its excellent performance in classification tasks, its ability to handle imbalanced datasets (often seen in species presence/absence), and its interpretability.
​Feature Set: This model's features are the primary geographical and temporal components, augmented by the predicted environmental conditions from Tier 1:
​latitude, longitude, day_sin, day_cos
​predicted_sst (from Tier 1)
​predicted_ssha (from Tier 1)
​predicted_chlor_a (from Tier 1)
​Training Data: The classifier was trained on the integrated dataset of shark presence (actual sightings) and pseudo-absence records (strategically generated non-sightings) from the OBIS dataset (2020-2025). Each record was augmented with its corresponding historical environmental conditions.
​Target Variable: presence (binary: 1 for presence, 0 for absence).
​Hyperparameter Tuning (Optuna):
​Methodology: Similar to Tier 1, Optuna was used to optimize the classifier's hyperparameters.
​Objective Function: The primary objective was to maximize the Area Under the Receiver Operating Characteristic Curve (AUC-ROC) score, which is a robust metric for classification models, especially with imbalanced datasets.
​Key Parameters Optimized:
​n_estimators, learning_rate, num_leaves, max_depth, min_child_samples, subsample, colsample_bytree, reg_alpha, reg_lambda (similar to regressors).
​scale_pos_weight: This crucial parameter was specifically tuned to handle the inherent imbalance between shark presence and absence records in the training data, giving more weight to the less frequent "presence" class.
​Performance: The optimized shark presence classifier achieved an outstanding AUC-ROC score exceeding 0.99. This indicates that the model has learned to powerfully discriminate between environmental conditions associated with shark presence and absence, providing highly reliable probability estimates for potential shark hotspots.
​4. Robustness and Scalability
​Robust Scaling (SSHA): For the SSHA model, a RobustScaler was specifically applied during preprocessing and integrated into the model saving/loading process. This scaler is less prone to outliers than standard scalers, making the SSHA predictions more stable and scientifically plausible, especially when dealing with extreme eddy events.
​Model Persistence: All trained models (including the SSHA RobustScaler) were saved using joblib. This allows for efficient loading and deployment within our prediction pipeline without retraining, ensuring that the web application can provide rapid, real-time forecasts.
​In summary, the "Sharko" predictive model stack represents a carefully designed and rigorously optimized system that leverages cutting-edge machine learning techniques and extensive satellite data to provide unprecedented insights into shark habitat prediction.
