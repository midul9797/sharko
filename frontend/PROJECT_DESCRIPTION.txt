# Shark Tracking and Visualization Project - Complete Technical Documentation

## Project Overview
This is a React-based web application for predicting and visualizing shark presence and habitat data using interactive 3D maps and immersive storytelling. The project combines machine learning predictions, interactive mapping, and AI-powered assistance to provide insights into shark behavior, hunting patterns, and migration routes. The application features a comprehensive storytelling experience through six video chapters that explain how sharks hunt, navigate, and maintain ocean ecosystems, while the interactive map displays prediction polygons showing where sharks are likely to be found based on environmental factors and species-specific foraging behaviors.

## Core Architecture

### Main Application Structure
- **Framework**: React 18.2.0 with TypeScript
- **Build Tool**: Vite 5.0.8
- **Styling**: Tailwind CSS 4.1.13
- **Routing**: React Router DOM 7.9.3

## 1. Mapbox Component (src/components/Mapbox.tsx)
**Primary mapping interface for shark data visualization**

### Libraries Used:
- **mapbox-gl**: Core mapping library for interactive maps
- **lucide-react**: Icon components (ChevronRight, MessageCircle)
- **react-router-dom**: Navigation (Link component)

### Functionality:
- Interactive map with satellite imagery
- **Shark Presence Predictions**: Red polygons showing predicted locations where sharks could be present
- **Shark Habitat Predictions**: Green polygons showing predicted foraging habitats based on shark species
- Date-based data filtering (day, month, year selection)
- Shark species selection with detailed information panels
- Custom markers with click-to-fly animations
- API integration for data fetching (localhost:8000/predict/)

### Data Flow:
1. User selects date and shark species
2. Component fetches prediction data from backend API
3. GeoJSON prediction data is processed and rendered as colored polygons on map
4. Interactive markers allow detailed exploration of predicted hotspots
5. Real-time updates when parameters change
6. **Prediction Accuracy**: Data shows where sharks are likely to be based on environmental factors, ocean currents, and food availability

- **Ocean Food Web**: Details the invisible chain of life that drives every ocean movement

#### VideoHeroFive.tsx - "The Hunt Revealed"
- **Part 1 - Predicted Hotspot**: Confirms data accuracy - warm currents and phytoplankton create perfect hunting grounds
- **Part 2 - Why Her Hunt Matters**: Explains apex predator role in ecosystem health

#### VideoHeroSix.tsx - "From Prediction to Protection"
- **Real-World Applications**: Shows how data changes the world through human decisions
- **Three User Groups**:
  - **Fishermen**: Use hotspot maps to avoid high shark activity, reducing bycatch and saving gear
  - **Conservationists**: Use data to establish Marine Protected Areas (MPAs) for critical habitats
  - **Public Safety**: Coastal managers issue accurate beach advisories for swimmer safety
- **Global Impact**: Demonstrates how improved predictions create safer oceans for everyone
